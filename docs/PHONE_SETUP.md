| Что | Зачем |

| Компьютер с Ubuntu | Сборка и установка приложения |
| Honor 50 Lite (или другой Android 8.0+) | Телефон для детского плеера |
| USB-кабель (желательно оригинальный) | Связь телефона с компьютером |

| ~2 ГБ свободного места на диске | Gradle, SDK, сборка |

**Важно про кабель:** некоторые кабели только заряжают, но не передают данные. Если телефон не виден в `adb devices` — попробуйте другой кабель.

## 2. Подготовка Ubuntu

Откройте **Терминал**: `Ctrl+Alt+T` (или найдите «Terminal» в меню приложений).

### 2.1. Обновить систему (рекомендуется)

```bash
sudo apt update
sudo apt upgrade -y
```

### 2.2. Установить Java 17

Приложение собирается на Java 17. Без неё сборка не запустится.

```bash
sudo apt install -y openjdk-17-jdk
```

Проверка:

```bash
java -version
```

Должно быть что-то вроде:

```
openjdk version "17.0.x"
```

### 2.3. Установить ADB (Android Debug Bridge)

ADB — программа, через которую компьютер «видит» телефон и устанавливает приложение.

```bash
sudo apt install -y android-tools-adb android-tools-fastboot
```

Проверка:

```bash
adb version
```

Должна появиться версия, например: `Android Debug Bridge version 1.0.41`.

### 2.4. Правила udev для Android (чтобы Ubuntu видел телефон)

На Linux телефон часто **не определяется** без этих правил. Сделайте один раз:

```bash
sudo tee /etc/udev/rules.d/51-android.rules > /dev/null <<'EOF'
# Google / Android
SUBSYSTEM=="usb", ATTR{idVendor}=="18d1", MODE="0666", GROUP="plugdev"
# Huawei / Honor
SUBSYSTEM=="usb", ATTR{idVendor}=="12d1", MODE="0666", GROUP="plugdev"
EOF

sudo usermod -aG plugdev $USER
sudo udevadm control --reload-rules
sudo udevadm trigger
```

После `usermod` **перезайдите в систему** (выйти и войти) или перезагрузите компьютер. Иначе группа `plugdev` не применится.

### 2.5. Скачать проект (если ещё не скачан)

Если проект уже лежит на диске — перейдите в его папку:

```bash
cd /home/dima/video-game
```

Замените путь на свой, если папка в другом месте.

Проверка — в папке должны быть файлы `gradlew` и `README.md`:

```bash
ls
```

## 3. Подготовка телефона

Все действия — **на телефоне**, пальцем по экрану.

### 3.1. Включить режим разработчика

1. Откройте **Настройки**
2. Прокрутите вниз → **О телефоне** (или **Система → О телефоне**)
3. Найдите строку **Номер сборки** (Build number)
4. **Нажмите на неё 7 раз подряд**
5. Появится сообщение вроде «Вы стали разработчиком»

Если спросит PIN/пароль экрана — введите.

### 3.2. Включить отладку по USB

1. Вернитесь в **Настройки**
2. Откройте **Система и обновления** → **Для разработчиков**  
   (на MagicOS путь может быть: **Настройки → Система → Для разработчиков**)
3. Включите переключатель **Отладка по USB** (USB debugging) — **ВКЛ**

Рекомендуется также включить (если есть):

- **Оставаться активным** (Stay awake) — экран не гаснет при зарядке от USB
- **Установка через USB** (Install via USB) — если такой пункт есть на Honor

### 3.3. Подготовка к режиму киоска (Device Owner)

Для **полного киоска** (ребёнок не может выйти из приложения) на телефоне **не должно быть аккаунтов**:

- Google-аккаунт
- Honor ID / Huawei ID
- Любые другие аккаунты

**Если аккаунты уже есть** — два варианта:

| Вариант | Что делать | Результат |
|---------|------------|-----------|
| **A. Полный киоск** | Сброс к заводским настройкам, **не** добавлять аккаунты при первой настройке | Device Owner работает |
| **B. Без сброса** | Оставить как есть | Только «закрепление экрана», слабее |

Как сбросить (вариант A):

1. **Настройки → Система и обновления → Сброс → Сбросить настройки телефона**
2. Подтвердить сброс
3. При первой настройке **не входить** в Google / Honor ID
4. Сразу включить отладку по USB (раздел 3.1–3.2)

## 4. Подключение телефона к компьютеру

### 4.1. Подключить кабель

1. Подключите телефон к компьютеру USB-кабелем
2. На телефоне может появиться вопрос **«Разрешить отладку по USB?»**
3. Поставьте галочку **«Всегда разрешать с этого компьютера»**
4. Нажмите **Разрешить** / **ОК**

### 4.2. Режим USB на телефоне

Потяните шторку уведомлений вниз. Нажмите на уведомление USB:

- Выберите **Передача файлов** (File Transfer / MTP)  
  или **PTP** — главное, не «Только зарядка»

### 4.3. Проверить, что компьютер видит телефон

В терминале на Ubuntu:

```bash
adb kill-server
adb start-server
adb devices
```

**Правильный результат:**

```
List of devices attached
ABCD1234567890    device
```

Слово в конце строки должно быть **`device`**.

**Плохие варианты:**

| Что видите | Что это значит | Что делать |
|------------|----------------|------------|
| Пустой список | Телефон не виден | Другой каб
ель, режим USB, udev (раздел 2.4), переподключить |
| `unauthorized` | Не подтвердили отладку на телефоне | Отключить кабель, снова подключить, нажать «Разрешить» |
| `no permissions` | Нет прав udev | Раздел 2.4, перелогиниться |
| `offline` | Сбой связи | `adb kill-server && adb start-server`, переподключить кабель |

Узнать модель телефона (для проверки):

```bash
adb shell getprop ro.product.model
```

Для Honor 50 Lite должно быть что-то вроде `NTN-LX1` или похожее.

## 5. Сборка приложения

В терминале, в папке проекта:

```bash
cd /home/dima/video-game
./gradlew assembleDebug
```

**Первая сборка** может занять 5–15 минут (скачаются зависимости).  
Дождитесь строки:

```
BUILD SUCCESSFUL
```

Готовый файл:

```
app/build/outputs/apk/debug/app-debug.apk
```

Проверка:

```bash
ls -lh app/build/outputs/apk/debug/app-debug.apk
```

Должен показать файл ~30–40 МБ.

**Если `./gradlew` пишет «Permission denied»:**

```bash
chmod +x gradlew
./gradlew assembleDebug
```

## 6. Установка на телефон

Телефон должен быть подключён, `adb devices` показывает `device`.

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

**Успех:**

```
Success
```

**Если пишет `INSTALL_FAILED_UPDATE_INCOMPATIBLE`:**

Сначала удалите старую версию:

```bash
adb uninstall com.dima.kidsvideoplayer
adb install app/build/outputs/apk/debug/app-debug.apk
```

## 7. Режим киоска (Device Owner)

Это **главный шаг** для полноценного детского режима:

- приложение запускается само в киоске;
- кнопка Home возвращает в приложение, а не на рабочий стол;
- шторка уведомлений заблокирована;
- экран блокировки отключён.

### 7.1. Назначить приложение владельцем устройства

```bash
adb shell dpm set-device-owner com.dima.kidsvideoplayer/.admin.MyDeviceAdminReceiver
```

**Успех:**

```
Success: Device owner set to package com.dima.kidsvideoplayer
```

**Проверка:**

```bash
adb shell dpm list-owners
```

Должно показать `com.dima.kidsvideoplayer`.

### 7.2. Если команда не сработала

Типичные ошибки:

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `not allowed` | На телефоне есть аккаунты | Удалить все аккаунты или сброс (раздел 3.3) |
| `already has an owner` | Уже назначен другой владелец | Сброс телефона |
| `component not found` | APK не установлен | Сначала `adb install` (раздел 6) |

### 7.3. Если Device Owner невозможен (не хотите сбрасывать)

Можно использовать **закрепление экрана** (слабее, но без сброса):

1. На телефоне: **Настройки → Безопасность → Закрепление экрана** — включить
2. Установить и запустить приложение (разделы 6 и 8)
3. При первом запуске подтвердить закрепление на экране телефона

## 8. Первый запуск и проверка

### 8.1. Запуск с компьютера

```bash
adb shell am start -n com.dima.kidsvideoplayer/.MainActivity
```

Или просто найдите на телефоне иконку **«Детский Видеоплеер»** и нажмите.

### 8.2. Что должно произойти

Если Device Owner настроен правильно:

- [ ] Приложение открылось на весь экран
- [ ] Экран в **горизонтальной** ориентации (landscape)
- [ ] Нет строки состояния / шторки сверху
- [ ] Кнопка **Home** возвращает в приложение, а не на рабочий стол Honor
- [ ] Ребёнок **не может** выйти жестом вбок / через «Недавние» / стрелку закрытия

Если жест вбок всё ещё открывает «Недавние» и позволяет закрыть приложение — переустановите **последнюю** версию APK (в ней отключены системные «лазеи» Lock Task). Проверка с компьютера:

```bash
adb logcat -d -s LockTaskManager | tail -5
# Должна быть строка: Lock task features disabled (no recents/home/power menu)
```

Если видео ещё не добавлены — экран плеера может быть пустым или с сообщением об отсутствии видео. Это нормально.

### 8.3. Проверка родительского доступа

1. Найдите на экране плеера **иконку шестерёнки** в **верхнем правом углу**
2. **Удерживайте палец 3 секунды** (long press)
3. Откроется **родительский экран** (список видео, кнопки управления) — PIN не требуется

PIN по умолчанию: **`1234`** (нужен для выхода из приложения и добавления видео).

### 8.4. Полный выход из киоска (только для родителя)

1. Удерживайте **шестерёнку** 3 секунды → родительский экран
2. Нажмите **«Снять киоск»**
3. Введите PIN (**1234**)

Приложение полностью снимает киоск: Lock Task, политики Device Owner (шторка, Home-лаунчер) и статус владельца устройства. После этого можно удалить APK: **Настройки → Приложения → Детский Видеоплеер → Удалить**.

### 8.5. Админский выход без приложения (ADB)

Если приложение зависло или забыли PIN — с компьютера:

```bash
adb shell dpm remove-active-admin com.dima.kidsvideoplayer/.admin.MyDeviceAdminReceiver
adb uninstall com.dima.kidsvideoplayer
```

### 8.6. Аварийный сброс (без ПК)

Сброс к заводским настройкам из Recovery снимает Device Owner полностью. На Honor рекомендуется отключить **Smart Recovery**, иначе система может перехватывать краши приложения.

## 9. Добавление видео

### 9.1. Скопировать видео на телефон (если их ещё нет)

**Способ A — через компьютер (ADB):**

```bash
# Создать папку на телефоне
adb shell mkdir -p /sdcard/Movies/Kids

# Скопировать видео с компьютера (замените путь на свой файл)
adb push /home/dima/Videos/cartoon.mp4 /sdcard/Movies/Kids/
```

**Способ B — вручную:** скопировать файлы на телефон любым удобным способом (USB как флешка, облако, мессенджер).

Поддерживаемые форматы: MP4, MKV, AVI и другие, которые понимает ExoPlayer.

### 9.2. Выдать разрешение на файлы (Android 13)

На Honor с Android 13 приложению нужен доступ ко всем файлам:

1. **Настройки → Приложения → Детский Видеоплеер**
2. **Разрешения → Файлы и медиа** (или «Другие разрешения»)
3. Выберите **«Разрешить доступ ко всем файлам»**

Или приложение само попросит при открытии файлового пикера — нажмите **Разрешить**.

### 9.3. Добавить видео через приложение

1. Удерживайте **шестерёнку** 3 секунды → родительский экран (без PIN)
2. Нажмите **«Добавить»** (или «Нажмите, чтобы выбрать видео», если список пуст)
3. Введите PIN **1234**
4. Откройте **файловый пикер** и перейдите в папку с видео (например `Movies/Kids` или `Download`)
5. Выберите видеофайлы или целую папку
6. Вернитесь в детский режим (кнопка «Назад» / выбор видео для воспроизведения)
7. Видео должно начать играть

### 9.4. Проверка воспроизведения

- Кнопки **вперёд / назад** переключают видео в плейлисте
- При выходе и повторном входе позиция воспроизведения сохраняется

## 11. Частые проблемы

### Телефон не появляется в `adb devices`

1. Другой USB-кабель
2. Режим USB: «Передача файлов», не «Только зарядка»
3. Правила udev (раздел 2.4) + перелогиниться
4. На телефоне снова подтвердить «Разрешить отладку по USB»
5. Попробовать другой USB-порт на компьютере

### `dpm set-device-owner` — not allowed

На телефоне есть аккаунт. Удалите все аккаунты или сделайте сброс к заводским настройкам **без** добавления аккаунтов при первой настройке.

### Приложение установилось, но киоск не работает

- Проверьте Device Owner: `adb shell dpm list-owners`
- Если пусто — либо сброс + Device Owner, либо включите закрепление экрана вручную (раздел 7.3)

### Файловый пикер пустой / не видит видео

1. Выдайте «Доступ ко всем файлам» (раздел 9.2)
2. Убедитесь, что видео реально лежит на телефоне:  
   `adb shell ls /sdcard/Movies/Kids/`
3. На Honor проверьте SD-карту отдельно, если видео на карте памяти

### Видео не воспроизводится

- Формат может быть несовместим (редкий кодек)
- Попробуйте обычный MP4 (H.264 + AAC)
- Посмотрите логи:  
  `adb logcat -s VideoPlayerManager VideoCompatibilityChecker`

### `BUILD FAILED` при сборке

```bash
java -version   # должна быть 17
```

Если Java не 17:

```bash
sudo apt install openjdk-17-jdk
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
./gradlew assembleDebug
```

### Посмотреть логи приложения в реальном времени

```bash
adb logcat -s MainActivity LockTaskManager
```

Полезно, если киоск не стартует или падает при запуске.

## 12. Приложение для Windows

Кратко — те же шаги, другие команды установки инструментов.

### Установить инструменты

1. **Java 17:** скачать с [adoptium.net](https://adoptium.net/) (Temurin 17)
2. **ADB:** скачать [Platform Tools](https://developer.android.com/tools/releases/platform-tools) от Google, распаковать, добавить папку в PATH
3. **Git** (если клонируете репозиторий): [git-scm.com](https://git-scm.com/)

Проверка в PowerShell или CMD:

```cmd
java -version
adb version
```

### Драйвер USB для Honor

Windows может не видеть телефон без драйвера. Установите **HiSuite** от Honor — вместе с ним ставятся USB-драйверы.  
Либо: Диспетчер устройств → найти неизвестное устройство → обновить драйвер.

### Сборка и установка

В PowerShell, в папке проекта:

```powershell
cd C:\path\to\video-game
.\gradlew.bat assembleDebug
adb devices
adb install -r app\build\outputs\apk\debug\app-debug.apk
adb shell dpm set-device-owner com.dima.kidsvideoplayer/.admin.MyDeviceAdminReceiver
adb shell am start -n com.dima.kidsvideoplayer/.MainActivity
```

Остальные шаги (подготовка телефона, PIN, добавление видео) — **те же**, что в разделах 3, 8 и 9.
