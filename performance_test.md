### 2. Измерение производительности

#### 2.1 Время загрузки папок
- Маленькие папки (< 50 файлов): < 500ms
- Средние папки (50-500 файлов): < 2s
- Большие папки (> 500 файлов): < 5s с прогресс-баром

#### 2.2 Использование памяти
- При работе с большими каталогами: < 100MB дополнительной памяти
- Кеширование: LRU cache с ограничением в 100 элементов
- Параллельная обработка: chunked processing с контролем памяти

#### 2.3 Отзывчивость интерфейса
- Быстрые действия пользователя: < 100ms отклик
- Переключение между папками: < 500ms
- Выбор/отмена выбора: < 200ms
